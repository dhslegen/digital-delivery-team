# 示例 C：比赛官网链接 → brief（含外部资源处理）

## 用户输入（实战）

> 我想用这次比赛项目作为 DDT 测试项目。
> 比赛官网：https://example-hackathon.com/2026
> 题目主线是"开发一个面向中小企业的智能客服平台"，
> 截止日期 6 月 15 日，要求 3 人团队 30 天完成。

## 输入识别

- 类型：C. URL + A. 自然语言描述（混合）
- 信号：含"比赛"、"hackathon"、"截止日期"、"评分"等比赛特征
- 路径：先 WebFetch 拉取官网内容 → 与用户描述合并

LLM 开场说："识别到比赛项目（URL + 描述）。将拉取官网获取评分标准、约束细节后再提取字段。先用 WebFetch 抓取..."

## 比赛项目特殊处理

比赛和普通项目的差异：

| 维度 | 普通项目 | 比赛项目 | brief 处理 |
|---|---|---|---|
| 成功标准 | 业务 KPI（DAU / 转化率） | **评分标准** | 把比赛评分项作为成功标准 |
| 关键约束 | 上线日期 | **比赛截止日期 + 团队规模** | 双约束硬写 |
| 用户 | 真实用户 | **评委 + 演示用户** | 两类都列 |
| 参考资料 | 竞品 | **官网链接 + 历届优秀作品** | 必填 |

## 字段提取（比赛特化）

### §1 项目背景
> 面向中小企业的智能客服平台。比赛要求展示对真实客户咨询场景的处理能力 + 多轮对话 + 知识库接入 + 工单流转。
> 痛点（业务侧）：中小企业客服成本高、人手不足，AI 客服可降低 60% 工单。
> 为什么现在做：比赛驱动 + LLM 成本下降至生产可用区间。

### §2 目标用户
- **主要用户（演示）**：中小企业客服经理（每天 50-100 工单分配，关注响应速度与一次解决率）
- **次要用户（评委）**：技术评委（关注架构 / 创新点 / Demo 完成度）+ 产品评委（关注用户体验 / 商业模式）

### §3 成功标准（**比赛评分标准 = 硬指标**）
从官网 WebFetch 拉到的评分项：
- [ ] 完成度（30 分）：核心 5 个功能全部可演示
- [ ] 创新性（25 分）：至少 1 个差异化技术点
- [ ] 商业可行性（20 分）：清晰的盈利模型
- [ ] 演示效果（15 分）：5 分钟 Demo 流畅
- [ ] 文档（10 分）：架构图 + API 文档完整

补业务可量化：
- [ ] 客户咨询的一次解决率 ≥ 70%（Demo 数据）
- [ ] 多轮对话 ≤ 3 轮收敛

### §4 核心功能
1. 客户咨询接入（Web 聊天窗口 / 嵌入企业网站）
2. 多轮对话（含上下文记忆）
3. 知识库接入（向量检索 + RAG）
4. 工单创建与流转（AI 解决不了时升级人工）
5. 数据看板（客服经理查看处理量 / 满意度 / TOP 问题）

### §5 关键约束（**比赛硬约束**）
- **截止日期**：2026-06-15（比赛截止，不可改）
- **预算 / 工期**：3 人 × 30 天 = 90 人天
- **合规 / 安全**：客户对话数据不可留存超 30 天 + 提交前必须能跑通 Demo
- **团队**：3 人（前端 1 / 后端 1 / AI 1）
- **比赛规则约束**：开源代码必须 MIT 许可 / 用第三方 LLM 须标注 / 数据集自备

### §6-8 决策门（D1/D2/D3）

**比赛项目特殊推荐**：

D1 技术栈预设 → 推荐 **node-modern**
- 理由：3 人小队 / 全栈 TS 减少协作成本 / shadcn 生态适合 30 天交付高保真 UI
- 备选：python-fastapi（如果 AI 1 人对 Python 更熟）

D2 前端类型 → 推荐 **spa**
- 理由：客服界面需高交互（实时聊天）/ 数据看板需图表

D3 AI 通道 → 推荐 **claude-design**
- 理由：比赛个人成本敏感 / 零外部账号 / Hi-fi 设计能直接拿到评委演示

### §9 非目标
- 不做企业 SSO 接入（比赛 Demo 不需要）
- 不做大规模并发（演示用 100 用户即可）
- 不做手机原生 App（PWA 即可）

### §10 参考资料（**比赛必填**）
- 比赛官网：https://example-hackathon.com/2026
- 评分标准（细则）：https://example-hackathon.com/2026/judging-criteria
- 历届优秀作品：https://example-hackathon.com/2025/winners
- 业界对标：Intercom Fin / Zendesk AI / 智谱清言客服
